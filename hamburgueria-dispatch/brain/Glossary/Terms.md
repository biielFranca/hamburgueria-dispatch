# Terms

Project-specific terminology for Hamburgueria Dispatch.

## Domain Terms

### dispatch_suggestion
A route suggestion generated by the Route Engine. Contains 1–2 orders paired optimally, with suggested delivery sequence. Operator reviews it, selects a driver, and accepts or rejects it.

### route_eligibility
Classification of an order's eligibility to enter the dispatch queue. Values: `eligible`, `blocked`, `awaiting`, `external_monitoring`. Set by the Classifier.

### route_block_reason
Why an order was blocked or is awaiting. Values: `pickup_order`, `missing_coordinates`, `invalid_address`, `scheduled`.

### ClassifierService
Background React component that subscribes to new order insertions via Supabase Realtime and runs `classifyOrder()` on each.

### RouteEngineService
Background React component that triggers `runRouteEngine()` when orders become eligible.

### IfoodPoller
Background React component that polls iFood via Supabase Edge Function every 30 seconds.

### AlertSystem
Background React component that polls active orders every 20 seconds and fires time-based alerts.

### dispatch_ghost
Visual effect on the Operational map: dispatched orders fade out over 60 seconds. Tracked via `inProgress` array in Operational page state.

### store_id
UUID identifying the store/restaurant. Used for RLS — every resource is scoped to a store.

### @dispatch.internal
Synthetic email domain. All user auth emails follow `{username}@dispatch.internal` pattern since Supabase Auth requires email format but operators don't have personal emails.

### supabaseAdmin
A Supabase client initialized with service role key. Used for admin-level user operations. Requires `VITE_SUPABASE_SERVICE_KEY`.

### external_monitoring
Route eligibility state for platform-logistics orders (e.g. Keeta). These orders appear on the dispatch map but never enter the dispatch queue since the platform handles delivery.

### rejection_count
Counter on `orders` table. Increments each time a dispatch suggestion containing this order is rejected. After 3 rejections, order is marked `dispatch_timeout`.

### Open Delivery
Brazilian food delivery API standard. Used by 99Food, Keeta, and Cardápio Web. Hamburgueria Dispatch implements a multi-platform client for this standard.

## Naming Conventions

### Files
- Pages: `src/pages/PageName/index.tsx` + `PageName.css`
- Components: `src/components/ComponentName/index.tsx`
- Lib: `src/lib/featureName.ts`
- Integrations: `src/lib/integrations/platformName.ts`

### Variables
- camelCase for all TypeScript identifiers
- SCREAMING_SNAKE_CASE for constants (SESSION_DURATION, DISPATCH_GHOST_MS)
- Database columns: snake_case

### Branches / Commits
- No formal convention observed in codebase
